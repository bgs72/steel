# Steel

Steel is a user-space linux driver to control the background color of the MSI-GS60-6QE laptop SteelSeries keyboard and Rival-100 mouse.

Supported Hardware:

- MSI-GS60-6QE laptop keyboard
- Rival-100 mouse

Supported Platforms:

 - Fedora 44 (see [readme.txt](systemd/readme.txt) for installation details)
